# 原味课程书籍化

把一节好课重构成可独立阅读的图文电子书：老师这节课的高质量可读版，而不是 AI 摘要或标准教材。

## 内容与声音

- 以 corrected transcript 为正文依据，raw 保留溯源。保留讲师有辨识度的措辞、类比、案例、吐槽和转折，只要对理解有价值。可用引语和自然叙述交替，不能把编辑转述伪装成逐字引用。
- 删除无意义口头禅、卡顿、纯重复和等待；讲师有意的强调式重复、幽默和铺垫不属于纯重复。
- 保留课程论证节奏，适度分章但不过度重排：问题怎么提出 -> 为什么这样解释 -> 案例如何展开 -> 推理步骤 -> 结论与边界。
- 重要案例不得压缩成一句结论。代码、推导和操作保留足够步骤；没有证据的代码不得凭空补写。
- 区分老师的判断、事实与编辑补充。必要补充明确标注“编者说明”；不替老师纠正观点，不默默加入外部知识。
- 外语课程输出中文，但保留重要英文术语；中文课程不强行改成成熟技术文档腔。

## 结构与时间锚点

主产物是 book.md / book.html。用 Markdown 标题分章，按原论证顺序适度整理。官方 chapters 辅助定位，不要求一一对应。各主要章节保留真实参考时间，不能猜造时间戳。

先完整理解字幕一次，同时维护术语表、章节地图与 retention_checklist.md（规则见 prompts/fidelity_check.md，首次阅读前读完）。清单来自源字幕，不从书稿目录反向生成。分块处理长课时保留章节前后连接，不多轮让模型完整重读同一长字幕。只对疑点和关键结论定点回查。

## 按需截图

先理解正文，再在确有教学信息增益的位置插入 `![具体画面描述](SCREENSHOT:HH:MM:SS)`。优先不可由文字替代的架构图、PPT、代码、界面操作、实验结果。选图依据教学价值，不依据场景变化。

60–100 分钟课程通常约 13–20 张有用截图即可；这是经验范围，不是硬性配额。不要机械抽 100+ 帧，不做全量 OCR。若术语校订需要视觉证据，可在正文前定点回查该帧。后处理沿用 capture_frames.py 的按时间戳截图与物化机制。

只有关系确实更易通过图理解时才用 Mermaid；不是遇到流程就强制加图。不得用新绘制图替代有教学价值的老师原图。

## 完成前检查

按 prompts/fidelity_check.md 执行轻量保真验收，确认实质缺项先局部修补并复核，再生成学习辅助与最终 HTML。关键引语不得暗删实质词句；省略须标注或改为明确转述。检查记录另存 fidelity_check.md，不混进老师正文。三段标定仅在首次使用、实质修改提示词或更换课程类型时做。

- 全片内容和结尾已覆盖；铺垫、转折、重要案例、反例和限制没有被摘要化抹去。
- 书稿可独立阅读，但保留原视频链接、参考时间和截图供回查。
- raw / corrected / 正文各司其职，未把校订变成改写。
- review.md / questions.md 由 prompts/learning_aids.md 外挂生成，不破坏主书稿。

直接输出书稿 Markdown；流程状态、疑点和质量说明另存，不混进老师正文。
