# 第 1.5 步（增强）：课程官方讲义 + 4K 幻灯片

不少课程在录像之外还维护自己的主页（讲义 + 幻灯片课件，例如 `https://jyywiki.cn/GSE/2026/`）。
讲义是讲师本人的书面描述（权威术语、章节骨架、参考链接），幻灯片可渲染成 4K 图片，比任何视频帧都清晰。
先确认该课程是否有主页（用户给出，或按课程名自行搜索）；**没有主页就跳过本步，后续流程完全不变**。

## 时机

建议在**第二步生成 `book.md` 之后、第三步截帧之前**执行：SLIDE 占位符先被物化，
`capture_frames.py` 只会补拍剩下的 SCREENSHOT 帧（它本来就只截缺失帧）。

## 抓取 + 渲染

```bash
python src/course_assets.py <video_id> --course-url <课程主页> [--lecture N]
```

- 按视频标题自动匹配讲次；不匹配时用 `--list` 查看讲次表、`--lecture N` 手工指定。
- 产出 `output/<video_id>/course/`：`*.notes.md`（讲义 Markdown）、`slides_text.md`（每页幻灯片标题 + 要点）、
  `slides/slide_NNN.png`（4K 渲染图），并把 `book.md` 里的 `![...](SLIDE:n@HH:MM:SS)` 占位符物化为官方图。
- 渲染相关参数：`--width` / `--height`（默认 1920x1080）、`--scale`（默认 2，即输出 4K PNG）、`--force`（重渲染已有 PNG）。
- **提权**：渲染幻灯片要启动 headless Chrome，**需沙箱外执行**；只抓取不渲染（`--no-render`）沙箱内即可。

## 讲义怎么用（第二步写书时）

1. **术语以讲义为准**：专有名词、英文术语、人名、工具名、课程名一律采用讲义写法（用于压制字幕 / ASR 同音错词）。
2. **章节骨架对齐讲义**：在视频讲述顺序允许的前提下，章节标题与讲义的 `##` 小节保持一致或显式呼应。
3. **事实冲突以讲义为准**：字幕含糊、破碎或与讲义矛盾时，按讲义的表述改写该事实句；但**不得整段照抄讲义** ——
   本书仍是课堂口语记录的重构，讲义只用于校准与补全。
4. **参考链接必须保留**：讲义中的外部链接（论文 / 文档 / 文章）收集到文末「附：官方参考与延伸阅读」一节并注明对应章节；
   课堂口头提到而字幕丢失出处的，以讲义链接补全。
5. **出处与许可**：书首信息块与文末必须给出课程主页 / 讲义 / 幻灯片链接及版权说明（讲义通常带 CC 许可，照抄其许可名与作者署名）。

## 幻灯片覆盖铁律（铁律 8）

官方幻灯片的**每一页**都必须在 `book.md` 中**恰好出现一次**：课堂讲到的页按讲述顺序插 `SLIDE:n@HH:MM:SS`，
课堂没讲到的页（备份页等）统一放进文末「附录：课堂未展示的幻灯片」。交稿前自检：

```bash
python src/course_assets.py <video_id> --audit           # 有重复 / 遗漏即以退出码 1 结束
python src/course_assets.py <video_id> --locate-slides   # 抽样视频，定位每页幻灯片的首次出现时间（截帧，需沙箱外）
python src/course_assets.py <video_id> --weave           # 自动修复：重复图去重保留首次、缺失页按首现时间插入对应小节、课堂未展示的页进附录；修复后自动复审
```

## 截帧后升级：把「画面即幻灯片」的糊帧换成官方渲染图

```bash
python src/course_assets.py <video_id> --course-url <课程主页> --match-shots --no-render
```

- 脚本把每张 `images/shot_*.png` 与官方幻灯片渲染图做感知哈希（dHash）比对并打印候选：
  distance 越小越像，**<= 55 通常是「画面即幻灯片」，> 60 基本是演示 / 板书帧**。
- Agent 抽查确认后，把确认结果写成 `{"shot_00_00_55": 1, ...}`（值 = 幻灯片编号）的 json，再执行：

```bash
python src/course_assets.py <video_id> --apply-map <json路径>
```

- 糊帧即被替换为 4K 官方渲染图，原视频帧自动备份到 `images/video_frames/`。
- **校验技巧**：讲师按顺序翻页，匹配出的幻灯片编号沿时间轴应**单调不减**；出现乱序的候选基本是误匹配。
- 相关参数：`--step`（探测采样步长秒，默认 20）、`--threshold`（dHash 距离阈值，默认 55）。
- 最后重跑第四步 `post_process.py` 生成新 HTML。
